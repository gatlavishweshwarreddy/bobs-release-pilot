# 🚀 Bob's Release Pilot

> AI-powered release safety assistant using IBM Bob 2.0

## The Problem

Teams break production every day — not because of bad code, 
but because of missed breaking changes, untested paths, and 
rushed releases. Existing tools review code quality, but 
nothing checks if your release is actually **safe to ship**.

## The Solution

Bob's Release Pilot uses IBM Bob 2.0's full repository context 
to analyze your codebase before every release and answer:

- ⚠️ Are there breaking changes?
- 🧪 Are all changed files properly tested?
- 📋 Is there a migration script if needed?
- 🔗 Which API consumers are affected?
- 🚦 Is this release safe to ship?
